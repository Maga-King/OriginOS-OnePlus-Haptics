Nyako v0.3.0-demo2：修复上一版普通短震动没有输出的问题，并增加元模块挂载包。

`demo1` 把按键也送进了流式输出，短波形可能在驱动完成预填充、实际启动马达之前就被停止。HAL 返回成功不能证明产生了触感。该版已撤回，建议使用稳定版 0.2.1 或本修正版。

这版普通短震动恢复原来的直接输出。较长波形的混合输出补齐 1000 字节预填充、结束标记和 FIFO 完成等待；正常会话与短触感分别取消。输入法 effect 2、AI 唤醒与 765 个既有场景的波形没有改动。

- 本机已有 mountify 时，使用 `Nyako-OriginOS-Haptics-Metamodule-v0.3.0-demo2.zip`，由现有元模块挂载 ODM HAL 和 `/system/lib64/` 插件；不使用自挂载、监督进程或早期 initrc。安装步骤见 [元模块说明](https://github.com/Maga-King/OriginOS-OnePlus-Haptics/blob/main/docs/METAMODULE.md)。
- 原自挂载 ZIP 和手动内置 ZIP 继续保留，三种包使用同一次编译的 HAL。
- 插件只补发通知期间非循环、单个预设、最长 120 ms 的短触感。多段组合、HE 和铃声冲突尚未接入补发。短触感遇到正在直接播放的短会话时暂时等待，不能宣称全场景同时播放已经完成。
- 插件源代码可见，但编译需要有权限访问的 Nyako API 与现有核心；Action 完整编译 HAL，并打包我们编译的插件二进制，公开仓库不包含私有核心。

主机回归通过；目标驱动日志确认了修正后的预填充与播放启动。HAL 热更新后用户已确认普通按键恢复正常。插件 0.1.1 增加了本机实际使用的单振子 Stereo 请求，完整重启后的补发链路仍需复核。不安装插件也可以使用 HAL，但框架拦下的短触感不会自动恢复。

**回一加主系统前务必停用震动模块，元模块本身可以保留。用过旧版 initrc 注入时，停用或更新后执行 `ksud initrc refresh`。系统插件需要完整重启回 DSU 生效。**

HE/FMQ、原始音频和性能适配等原有未完成项不在本次完成范围内。
