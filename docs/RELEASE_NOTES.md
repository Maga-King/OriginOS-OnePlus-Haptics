# 0.3.0-demo4：修复长震动，并扩大短触感混音范围

此前 demo2 的长波形会在约半秒到一秒后停止。这次修复驱动槽位补数据和长度交接，保留原来的输入法、AI 唤醒与所有场景映射。修正版实机诊断播放 3 秒波形约 2993 ms，叠加和分别取消也完成；用户场景的实际手感仍需复核。

插件更新为 0.1.2，允许部分短触感混入通知、铃声、闹钟等已有普通会话；不再只限通知。思路借鉴一加官方 AAC 库的逻辑队列、按来源取消与样本混合。两路逻辑波形最后统一成一路物理输出，没有增加第二个马达输出线程。

这仍是被优先级拒绝后由插件送入 HAL 的短触感，不是框架原生的多个正常会话。多段组合、HE、Vendor/External 会话不在本插件范围内；权限、AppOps、设置和勿扰判断保留。详情见 [混音规则](https://github.com/Maga-King/OriginOS-OnePlus-Haptics/blob/main/docs/MIX_RULES.md)。

- 已有元模块使用 Metamodule 包，HAL 与插件一起挂载。
- 原自挂载模块包继续保留；单独使用它时需另装插件。
- 手动内置包增加 system 插件和两份配置增量，需手动合并，并重新打包 odm 和 system。步骤见包内 PLUGIN_BUILTIN_CN.md。
- 插件更新必须完整重启回 DSU；热更新 HAL 不会重载已加载的插件。

回一加主系统前必须停用震动模块，否则会卡二。本版没有新增安装或开机校验。

开发回归覆盖波形、HE、并发队列、混音、RTP 边界和槽位竞争，765 个场景输出保持一致。构建检查不能代替实机验收。插件 0.1.2 的范围调整仍待重启后的通知、铃声与快速打字复核。

demo1 和 demo2 不再推荐；稳定版 0.2.1 继续保留。HE/FMQ、性能适配等原有未完成项不在本次完成范围内。
